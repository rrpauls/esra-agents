# Contributing

Keep changes small, evidence-backed, runtime-neutral by default, and compatible
with ESRA 1.2.

1. Put portable procedural guidance under `skills/` and host differences under
   `adapters/` or `distributions/`.
2. Preserve routine-task bypass, focused-skill autonomy, and the one-review
   limit.
3. Keep runtime code dependency-free and lifecycle hooks silent, non-blocking,
   non-steering, and privacy-allowlisted.
4. Add or update tests for skill, runtime, adapter, packaging, or conformance
   changes.
5. Write a short `docs/oversight/` proposal before structural skill or runtime
   changes.
6. Distinguish unit, package, and native-host evidence in every capability
   claim.

Before opening a pull request, run the commands in `AGENTS.md`.
