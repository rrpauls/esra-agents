## 2024-10-25 - Path Traversal bypass via PurePosixPath
**Vulnerability:** A path traversal check using `PurePosixPath` in `safe_relative` can be bypassed by using backslashes (`\`) instead of forward slashes (`/`), since POSIX paths do not recognize backslashes as path separators.
**Learning:** Functions designed to sanitize paths must explicitly account for multiple path separator styles (like Windows backslashes) when processing input, especially if the sanitized path might later be used on platforms where those separators are active.
**Prevention:** Explicitly reject backslashes (`\`) in path validation before passing the string to Posix-specific path objects, or use cross-platform path validation strategies.
## 2024-10-31 - Symlink Refusal Bypass via Broken Symlinks
**Vulnerability:** Security checks that verify if a file is a symlink using `path.exists() and path.is_symlink()` can be bypassed by attackers providing a *broken* symlink. Because `path.exists()` resolves the symlink, it returns `False` if the target does not exist, causing the entire symlink check to evaluate to `False` and allowing the broken symlink through the check.
**Learning:** Checking for file existence before checking for symlink status introduces a TOCTOU-like vulnerability where broken symlinks bypass the check, potentially allowing an attacker to write files outside of intended directories when the application later writes to the validated path.
**Prevention:** Check for symlinks directly using `path.is_symlink()` without a preceding `path.exists()` check. Python's `pathlib.Path.is_symlink()` gracefully handles missing files, returning `False` if the path doesn't exist, making the `exists()` check both unnecessary and insecure.
## 2024-11-13 - DoS via NotADirectoryError in pathlib.rglob
**Vulnerability:** A Denial of Service (DoS) or application crash could occur if a path targeted for a recursive glob (`path.rglob('*')`) turns out to be a file rather than a directory. `pathlib` raises a `NotADirectoryError` when this occurs.
**Learning:** Checking `target.exists()` before `target.rglob()` is insufficient because it doesn't verify the path is a directory. If an attacker controls the target path, they could point it to an existing file, causing an unhandled exception and crashing the system.
**Prevention:** Replace `path.exists()` with `path.is_dir()` before attempting to use `rglob()` to ensure the target is actually a directory.
## 2026-10-24 - Fix Unsafe `rglob` and TOCTOU in `exists`
**Vulnerability:** Invoking `.rglob()` on a file instead of a directory in `runtime/esra_controller.py` raised a `NotADirectoryError` when processing file targets. Additionally, missing `is_symlink()` checks before `.exists()` calls in `scripts/verify_installations.py` could allow Time-of-Check to Time-of-Use (TOCTOU) bypass via broken symlinks.
**Learning:** Python's `pathlib` enforces that `.rglob()` should only be called on directories. Calling it on files crashes the application, enabling potential Denial of Service if the target path can be manipulated by users or agents. File existence checks using `path.exists()` can follow symlinks, leading to TOCTOU vulnerabilities if the symlink is changed between validation and execution.
**Prevention:** Always ensure `path.is_dir()` is checked before calling `.rglob()` to avoid crashes on files. Always check `path.is_symlink()` prior to using `path.exists()` to safely validate symlinks and prevent bypasses.
